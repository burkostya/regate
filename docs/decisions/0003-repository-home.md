# ADR-0003: GitHub repository as development source

Status: Accepted · 2026-11-15

The canonical source repository for Regate is `https://github.com/burkostya/regate`.

The first imported revision is an **engineering prototype** preserved from the previous sandbox artifact. It is not considered a production release. Track subsequent implementation through feature branches, pull requests and release gates in `docs/release-status.md`.

Only HTTP transport is supported for MCP. HCL is the executable configuration source. The UI layout remains non-executable.
